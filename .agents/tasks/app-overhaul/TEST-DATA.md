## Test Images

Untuk testing upload, siapkan gambar dengan spesifikasi:

### Cover/Hero Photo
- **Ukuran:** 1920x1080 px atau lebih (landscape)
- **Format:** JPG atau PNG
- **Ukuran file:** < 5MB
- **Sumber test image:** Gunakan foto pemandangan atau stock photo

### Couple Photos
- **Ukuran:** 800x800 px atau lebih (square/portrait)
- **Format:** JPG atau PNG
- **Ukuran file:** < 3MB per foto
- **Jumlah:** 2 foto (pria & wanita)
- **Sumber test image:** Gunakan avatar atau portrait photos

### Gallery Photos
- **Ukuran:** 1200x800 px atau lebih
- **Format:** JPG atau PNG
- **Ukuran file:** < 3MB per foto
- **Jumlah:** 3-6 foto
- **Sumber test image:** Gunakan foto landscape atau portrait mix

## Expected Results Reference

### Successful Create Event
```
✅ HTTP Status: 201 Created
✅ Response contains: { id, slug, template_id, ... }
✅ Redirect to: /events/{id}/edit or /events/{slug}/edit
✅ Success toast/message shown
✅ Console: No errors
```

### Successful Image Upload
```
✅ HTTP Status: 200 OK
✅ Response contains: { path, fullPath, ... }
✅ Image preview updates immediately
✅ Console: No errors
```

### Successful Update Event
```
✅ HTTP Status: 200 OK
✅ Response contains updated data
✅ Success toast/message shown
✅ Preview refreshes with new data
✅ Console: No errors
```

### Successful Public Page Load
```
✅ HTTP Status: 200 OK
✅ All text matches saved data
✅ All images display (no broken images)
✅ Template layout preserved
✅ Interactive elements work (RSVP, music, map)
✅ Console: No critical errors
```

## Common Test Scenarios

### Scenario A: Complete Flow (New User)
1. Visit homepage → Create account/login
2. Go to /events/create
3. Select template
4. Fill form with test data
5. Submit → Create event
6. Edit event → Upload photos
7. Save changes
8. View public page
9. Verify all data correct

**Expected time:** 15-20 minutes per template

### Scenario B: Edit Existing Event
1. Login
2. Go to dashboard/my events
3. Select existing event
4. Edit text fields
5. Upload new photos
6. Save changes
7. View public page
8. Verify changes applied

**Expected time:** 5-10 minutes per event

### Scenario C: Template Comparison
1. Create 2 events with different templates
2. Use same test data for both
3. View both public pages side-by-side
4. Verify each template has unique design
5. Verify data displays correctly in both

**Expected time:** 30 minutes for 2 templates

## Troubleshooting Guide

### Issue: Form submit fails
**Check:**
- Console errors
- Network tab for failed request
- Request payload (is data valid?)
- Authentication (is user logged in?)

### Issue: Image upload fails
**Check:**
- File size (< 5MB?)
- File type (JPG/PNG?)
- Network tab error details
- Supabase storage bucket permissions

### Issue: Public page shows old data
**Check:**
- Hard refresh (Ctrl+Shift+R)
- Check if save actually succeeded
- Verify data in Supabase dashboard
- Check browser cache

### Issue: Template looks wrong
**Check:**
- Is correct template HTML loaded?
- Check for CSS errors in console
- Verify template_id in database
- Check for missing assets (fonts, images)

### Issue: Console errors present
**Identify type:**
- Application error → Must fix
- Third-party warning → Usually safe to ignore
- Network error → Check API/Supabase
- TypeScript error → Check build
